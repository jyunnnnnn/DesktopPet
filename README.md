# AIchanDesk - 你的桌面小可愛們

![小克、GPT、大肥魚、Gemini、GLM、千問](docs/images/cover.png)

住在 Windows 工作列上的 AI 娘桌寵。可以同時叫出好幾隻，她們會自己走來走去、互相聊天、搶東西吃。你可以摸頭、拎起來甩、丟出去、餵食、猜拳、陪你讀書。

> 非官方同人作品，與 Anthropic、OpenAI、DeepSeek、Google、智譜、阿里巴巴無關。角色立繪來自 [CrossPet](https://github.com/lokicorvus/crosspet)，詳見 [致謝與授權](#致謝與授權)。

## 跟 CrossPet 的關係

本專案的角色立繪來自 **[CrossPet · 跨 AI 桌寵](https://github.com/lokicorvus/crosspet)**，互動設計也參考了它，例如甩到生氣、貼邊、依時段打招呼。

兩者的方向不同：
- **CrossPet**：「AI 在做什麼，她就做什麼」。它會接上 Claude Code、Codex、DeepSeek 等 AI 工具，即時演出 AI 的工作狀態，也會顯示額度。**如果你想要的是陪 AI 工作的桌寵，請用 CrossPet。**
- **AIchanDesk**：不連接任何 AI 工具，單純是**桌面上的小可愛**。重點放在多隻角色同時在場的互動、小遊戲和生活提醒。

## 功能

**跟她互動**
- 點一下摸頭；她生氣時摸她是在哄她，睡著時會被叫醒
- 拎起來：慢慢拖就像被拎著乖乖垂著；快速左右甩才會晃起來，用力畫圈會整圈轉；甩太多會暈、會生氣
- 丟出去會飛、撞牆反彈，摔太大力會頭暈；**往上甩是飛高高**，她會邊轉圈邊開心大叫，在空中可以接住她
- **在她身上往上滾滾輪**：直直往上起飛，空中再滾會飛得更高；在空中**往下滾**，她會被直直壓下去，落地摔得頭暈。上下滾來滾去，就可以把小可愛們當籃球運球 🏀
- **滑鼠碰到她來回晃＝一直摸**：頭上、身上都可以，來回晃幾下就跟摸摸頭一樣，會冒愛心
- **滑鼠在她頭頂上方、沒有碰到她來回晃＝逗貓棒**，她會跳起來跟你玩（Gemini 特別愛玩）
- 丟到螢幕最左或最右邊會貼邊，只露半個身子，滑鼠靠近時會探頭
- 中鍵或 Ctrl＋點一下是戳她
- **好感度**：摸頭、餵食、抱抱、陪玩都會加分，共 10 級，每級有稱號（初次見面 → 朋友 → 摯友 → 永遠在一起）；Lv3 摸頭會說真心話，Lv5 每天送你一個小禮物
- **惹她生氣**：捏臉頰、彈額頭、摸亂她的頭髮、說她胖、搶她的點心，怒氣條會一路漲（不耐煩 → 鼓臉 → 氣炸）。放著會慢慢消，對她好消得更快；**怒氣滿了會賭氣不理你**，要餵她吃東西才會明顯消氣
- **金幣**：陪她們就會賺，賺很容易：摸摸頭、來回摸、逗她玩、餵食、跟她玩、說說話、抱抱、玩器材、比賽、拍照、陪讀都有；每天簽到、升好感度、解鎖成就有大獎勵；只要她們在桌面上，每 5 分鐘還有陪伴獎勵。賺到的時候，數字會從她頭旁邊飄起來（控制面板「設定」可以關掉這個動畫，錢照樣賺）。右鍵選單最上面和「紀錄」分頁看得到現在有多少，第一次使用先送 60 枚
- **扭蛋（抽卡）要花金幣**：一次 30 枚，像扭蛋機一樣「投幣 → 扭蛋中……」；錢不夠她會跟你說；抽到重複的卡退回 10 枚。右鍵「跟她玩 → 抽卡」、小面板的「抽卡」、控制面板「圖鑑」分頁的「扭一次」都可以
- **跟她玩**：猜拳、比大小、猜糖果、抽卡（N／R／SR／SSR，抽到哪張她就演哪個動作，SSR 是節日裝，會記錄收集進度）、今日運勢（每天固定一個結果）、今天吃什麼、講冷笑話
- 她們偶爾會走到你的滑鼠底下揮手打招呼
- **撒嬌**（預設關閉）：她會抓你的滑鼠去玩：拉到頭上讓你摸、拿去戳自己的臉、吃進嘴裡嚼一嚼再吐出來、頂在頭上帶著跑。平常你一動滑鼠她就放手；打開「強制拖走」時滑鼠會被鎖住動不了，直到她放開（最多 9 秒）。右鍵選單的「撒嬌」可以馬上看

**好幾隻一起**
- 右鍵「叫誰來玩」，一次可以叫出一到六隻
- 靠近時會自己聊天，共 45 組對話：兩隻專屬的、三隻一起的、早上和深夜限定的，還有任兩隻都能用的
- 慢慢把一隻放到另一隻身上是抱抱；用力丟過去是撞飛，被撞的會生氣
- **請客**：她們偶爾會自己拿出一份點心（常常是對方愛吃的），走過去遞給朋友，對方開心地吃掉，兩隻好感度各加一點、你也賺金幣。別的小可愛不會搶這份點心；控制面板「設定」可以關掉
- 有一隻在賭氣時，其他隻會跑過去安慰她；一直摸同一隻，別隻會跑來吃醋；她們也會互相摸頭
- **疊高高**：從上面把一隻丟到另一隻頭上會疊起來，可以一直往上疊；只有最上面那隻開心、會說話、會自己跳下來，被踩在下面的都苦著臉、不說話也跳不起來，最底下的走動時上面的會跟著一起移動、一起搖搖晃晃
- **鬼抓人**、**捉迷藏**（大家躲到螢幕邊邊、從工作列探出頭，你要一隻一隻找出來）
- 大家一起：集合、排排站、開派對、賽跑、一起睡覺

**住在你的桌面上**
- **站在視窗上**：她們會跳到你開著的視窗頂端走來走去，拖動視窗會跟著移動，關掉、縮小視窗，或是你切到一個蓋住它的視窗（例如滿版的視窗），她們就會掉下來，不會浮在半空中
- **東西也能放在視窗上**：丟給她們的食物和球，掉在視窗頂端會停在上面，視窗移動跟著走，視窗不見或被蓋住就掉下去；地上的小可愛不會隔空吃視窗上的東西
- **看你在做什麼**：寫程式、看影片、聽音樂、打報告、看論文、聊天時會有不同反應（只在本機判斷，不會傳出去，可以關掉）
- 全螢幕看影片、玩遊戲時自動躲起來（設定裡可以關掉，讓她陪你看影片）；Ctrl+Alt+P 一鍵藏起來
- 系統匣有小克圖示，可以開控制面板、把走丟的大家叫回來
- 會自動檢查 GitHub 上有沒有新版本，有的話會跑出來跟你說，右鍵和系統匣會多一個「下載新版本」（設定裡可以關掉；只查版本號，不會送出任何資料）
- 支援多螢幕

**丟東西給大家**
- 飯糰、白飯、蛋糕、糰子、甜甜圈、草莓、香蕉、飲料（珍珠奶茶）、熱茶（都是自己畫的小圖，有高光和陰影）：掉在滑鼠的位置，大家搶著吃，大肥魚衝最快，沒搶到的會嘟嘴
- 足球、籃球、毛線球：她們會跑去踢；你也可以抓起來丟。玩具和球會跟著角色大小縮放
- **直接拿給她**：拿著東西靠近她會問「給我的嗎？」；放到她身上，食物會直接吃掉、玩具會接住踢出去；拿著食物在她頭上晃，她會跳起來搶；生氣時餵她會消氣
- 你手上拿的食物比掉在地上的更吸引她們，附近的都會跑過來等著搶；貼在螢幕邊的也可以餵，她會探出來吃
- 喝飲料、熱茶會說「好喝」；餵到她最愛的（小克的熱茶、大肥魚的白飯、Gemini 的香蕉）會有專屬台詞

**遊樂器材**（右鍵 →「遊樂器材」打開或收起）
- **籃球框**、**足球門**、**溜滑梯**、**鞦韆**、**蹺蹺板**、**彈跳床**，立體透視畫法，會跟著角色大小一起縮放
- 籃框和球門貼在螢幕最左或最右，兩個一定分在兩邊；拖到另一邊，另一個會自動換過去。溜滑梯可以拖到任何地方
- 她們會自己去投籃、射門、爬梯子溜滑梯；進球會開心歡呼、球有特效，沒進會小失落，旁邊的會安慰她
- 球進籃框、進球門有前後遮擋：前面的框和網子蓋住球，球蓋住後面的
- 有籃框時，最多一隻會躲在籃框柱子後面偷偷看你，滑鼠一靠近就被發現
- 鞦韆越盪越高、盪到最高會大叫，閒著的朋友有時會跑過來幫忙推，推一下盪得更高；蹺蹺板要兩隻才玩得起來，一隻坐上去會找朋友；彈跳床越跳越高，還會翻跟斗
- **兩隻一起玩**：籃框前鬥牛（搶球、蓋火鍋、喊比分，先進 3 球贏）、射門 PK（一隻當守門員撲球，踢 5 球）、溜滑梯排隊一個接一個
- **你也能玩**：拿起籃球、足球丟進去，大家會幫你歡呼，連進幾球、破紀錄都會講
- 想叫她去玩：右鍵 →「去玩器材」→ 溜滑梯、鞦韆、蹺蹺板、彈跳床、投籃、找人鬥牛、射門、找人當守門員、躲到籃框後面
- 飛很快的球砸到旁邊的小可愛，球會彈開，她會嚇一跳
- 叫她去玩但去不了的時候（有人在用、她正在比賽、被你拎著……），她會跟你說原因
- 她們永遠站在器材前面，點得到人、不會一直抓到器材
- 玩到一半把器材收起來、把球沒收，或突然叫她去做別的事，她都會乖乖下來，不會卡在半空中；丟一顆新的球、把器材擺回去，又可以繼續玩、繼續比賽
- 比賽到一半球被收走，她們會說「咦？球不見了！」

**誰來播音樂 🎧**（右鍵點她選「請她放音樂」、她自己的控制面板分頁，或「大家」分頁的「🎵 音樂播放器」）
- 請一隻小可愛當 DJ：播放器會換成她的代表色，中間的黑膠唱片貼著她的頭，播放時唱片會轉、唱臂會放上去；換 DJ 時音樂不會斷
- 播 `music` 資料夾（或你選的資料夾）裡的音樂：mp3、mp4（只放聲音）、m4a、aac、wav、wma、flac，子資料夾裡的也會列出來，歌名就是檔名。`music` 資料夾預設是空的，你放的歌不會被上傳
- 時間條可以拉、可以調音量、暫停、上一首／下一首、隨機播放、單曲重複；歌單是立體的卡片，按住上下拖或滾滾輪都能捲動，捲過最後一首會接回第 1 首；點兩下播放；按住卡片右邊的小點點上下拖可以換順序（會記住）。歌名太長會切掉，滑鼠移上去就用跑馬燈捲給你看；上面正在播的歌名太長也會自己跑馬燈
- **隨機播放**：每次按下隨機，歌單就會整個打亂一次（正在播的那首放第一個，繼續播），之後按下一首是照打亂的順序走，不會又跳回前面播過的；關掉隨機，歌單回到你排的順序，從正在播的那首接著往下（隨機到原本的第 13 首，關掉後下一首就是第 14 首）。隨機開著時拖曳換順序只動這一輪的順序，不會弄亂你排好的
- 沒有 Windows 的標題列：右上角的「－」縮到工作列（音樂繼續播）、「×」關掉（音樂就停）；按住上面空白的地方可以拖著移動
- 右上角第一顆鈕切換**小型／正常**：小型只有唱片和播放控制，正常版多了歌單和資料夾那排（打開資料夾、換資料夾、重新整理）。會記住你上次用哪一種
- 播放器是獨立的視窗：點桌面別的地方不會不見，也不會被其他程式的視窗蓋住，但會排在小可愛後面，她們還可以爬到播放器上面
- **換歌時，現在當 DJ 的那隻如果在桌面上，會跟你說新的歌名**；她不在桌面上（回家了、或大家都藏起來）也可以照樣聽，只是不會有人跟你說換歌
- 放音樂的時候，閒著的小可愛們會一陣一陣地跟著節奏搖擺跳舞，頭上偶爾飄出 ♪；正在比賽、排隊的不會被打斷
- 巨大化、休息的時候音樂繼續播，播放器會浮在最上面，直接用它控制就好

**拍照和相簿**
- 右鍵或系統匣的「拍照」：大家喊茄子，把桌面上的她們拍成一張拍立得，存在 `album` 資料夾
- 控制面板的「相簿」分頁可以看所有照片

**成就**
- 24 個成就（摸頭 100 次、你自己進 10 球、盪鞦韆 30 次、認識一週年……），解鎖時她會跑出來恭喜你，大家好感度 +1
- 解鎖的成就都可以當你的稱號，在「成就」分頁選

**她們自己的生活**
- 走來走去、眨眼、哼歌、伸懶腰、打哈欠，還有各自的專屬動作：小克抱 Clawd，大肥魚吃飯、摸魚、游泳，Gemini 飄起來，GLM 改價籤，千問送禮物
- 放著太久沒理會睡著；你離開電腦 10 分鐘她們會睡著，回來時會說「歡迎回來」
- 每個時段第一次見面有專屬的打招呼動作；元旦、春節、元宵、端午、中秋、萬聖節、聖誕節會換上節日裝扮
- 大肥魚有女僕裝、Claude 衛衣、睡衣、冬裝；GPT 有龍崽連身裝

**話題**（控制面板「話題」分頁）
- 讓她說：選一隻、打一句話按 Enter，她就會說出來
- 日常：平常的閒聊；認真：只講你勾選的專業話題，旁邊的會接話「原來如此！」；混合：兩種都有
- 內建類別：日常（喝水、伸懶腰、早點睡這種貼心的小提醒）、數位 IC（100 多句，時序、CDC、低功耗、DFT、驗證、AXI、佈局繞線、Verilog 寫法、上板除錯……）、軟體開發（50 多句）、醫護、金融、法律、設計，以及自訂類別。每一類的句子都可以新增刪除，也能新增自己的類別

**控制面板**（右鍵 →「開啟控制面板」，或點系統匣的小克）
- 沒有 Windows 的標題列：右上角「－」縮到工作列、「✕」關掉，按住上面那排拖著移動，右下角的小三角可以拉大小。縮小控制面板不會影響音樂播放器
- 「大家」：叫誰出來、大家一起、丟東西、陪讀、巨大化
- 「待辦」：寫下待辦事項，時間隨便打（9:30、930、9點半、下午3點、明天下午2點、30分鐘後、45秒後都可以），可以選誰來提醒你（她不在桌面上會自己跑出來），快到和時間到她都會來提醒；打勾完成她們會誇你。清單分成今天、之後、重複的、沒有時間的、已完成。下面還有「提醒我：5、10、25、60 分鐘後」快速按鈕
- 「圖鑑」：抽到的卡片一覽（還沒抽到的是剪影），點一張她會巨大化換成那張卡，只說話不做動作
- 「紀錄」：認識幾天、簽到天數、今天／這週／全部的統計（摸頭、餵食、遊戲、陪讀……）、每隻的好感度和抽卡收集
- 「相簿」：拍過的合照
- 「成就」：解鎖進度、選你的稱號
- 「設定」：大小、走路速度（慢／中／快）、各種開關、設定搬家（匯出／匯入）、你的生日、「今天吃什麼」的清單（可以新增刪除）
- 每隻角色一頁：頭像（名字旁邊的 ✎ 可以幫她改名）、好感度和怒氣條、稱號、互動、小遊戲、惹她生氣、所有動作、換衣服、請她放音樂

**巨大化模式**
- 只留一隻，佔滿整個螢幕高度。透明的地方點得穿，不影響你用電腦
- 摸頭、戳臉頰、碰身體的反應都不一樣；滑鼠碰到她來回晃是一直摸，會持續冒愛心
- 她會比平常更常說話，好感度高時說的話會更親密
- **休息模式 💤**：像電腦休眠，整個螢幕（連工作列）變暗，顯示大時鐘、日期和已經休息多久，她陪你休息。右鍵「陪我休息」、系統匣「休息模式」、控制面板、巨大化控制列都能進入；陪讀結束時會倒數 5 分鐘
- 右上角有控制列（可以縮小成兩顆小圓鈕）：背景暗度滑桿（一般巨大化、休息模式分開記）、換成抽到的卡片、開圖鑑、休息／不休息了、結束巨大化。控制面板開著時會浮在最上面
- 按 Esc 或控制列的「結束巨大化」結束

**換電腦**
- 「設定」分頁的「設定搬家」：舊電腦匯出成一個檔案，新電腦匯入，好感度、卡片、名字、成就、紀錄都會帶過去

**長期養成**
- 每日簽到（連續 7、30、100、365 天有特別慶祝）
- 設定生日，當天大家幫你慶生；認識滿 100 天、滿一年也會慶祝

**有時間觀念**
- 會看時間講話：「現在凌晨 3 點了，你還不睡覺！」「中午 12 點了，該吃午餐囉！」「下午 3 點了，要不要來點下午茶？」，星期一、星期五、週末也會有不同的話

**生活小幫手**
- 陪讀 25 分鐘：大家一起看書寫字，時間到提醒你休息
- 提醒我：5、10、25、60 分鐘後叫你（在「待辦」分頁，會變成一筆待辦）
- 整點提醒喝水、12:00 和 18:30 吃飯提醒、深夜催睡（都可以在設定裡關掉）
- 安靜模式、五種大小（右鍵選單直接切換）、開機自動啟動

## 安裝

**直接用**：[下載最新版 AIchanDesk.zip](https://github.com/jyunnnnnn/AIchanDesk/releases/latest/download/AIchanDesk.zip)，解壓縮後點兩下 `AIchanDesk.exe`。不用安裝，也不需要管理員權限。各版本的更新說明在 [Releases](../../releases)。

**從原始碼跑**（Windows 10 以上、Python 3.10 以上）：

```bash
pip install -r requirements.txt
python src/desktop_pet.py
```

**自己打包 exe**：

```bash
pip install pyinstaller pystray
pyinstaller --onefile --noconsole --name AIchanDesk --hidden-import pystray._win32 src/desktop_pet.py
```

把產生的 `AIchanDesk.exe` 放到跟 `characters/`、`fonts/` 同一層。

## 操作

| 操作 | 效果 |
|---|---|
| 左鍵點一下 | 摸摸頭 |
| 滑鼠碰到她來回晃 | 一直摸（跟摸頭一樣） |
| 滑鼠在頭頂上方來回晃（沒碰到） | 逗她，她會跳起來跟你玩 |
| 左鍵點兩下 | 跳一下；貼邊時是出來 |
| 左鍵拖曳 | 拎起來（畫圈會轉、左右甩會暈） |
| 放手 | 丟出去 |
| 在她身上滾滾輪 | 往上滾：垂直起飛，空中再滾飛更高；空中往下滾：直直壓下去，落地摔暈（上下滾就能把她們當籃球運球） |
| 中鍵 / Ctrl＋左鍵 | 戳一下 |
| 右鍵 | 日常選單（摸頭、餵食、跟她玩、去玩器材、巨大化、陪我休息、陪讀……）；其他都在控制面板 |
| 拖器材 | 溜滑梯隨便放；籃框、球門放開時貼到比較近的那一邊 |

## 自訂角色

一個資料夾就是一個角色，放在 `characters/` 底下：

```
characters/my-girl/
├── character.json   名字、顏色、台詞
├── idle.webp        必備；其他沒有的姿態都會用它代替
├── idle-2.webp      同一姿態的第二張，待機時會輪換
├── idle-blink.webp  眨眼（只有眼睛閉上，其他跟 idle 一模一樣）
├── pat.webp、happy.webp、surprised.webp、sleeping.webp……
```

- 姿態名稱和 CrossPet 相同，完整清單見 CrossPet 的 [自訂角色說明](https://github.com/lokicorvus/crosspet/blob/main/docs/%E8%87%AA%E5%AE%9A%E4%B9%89%E8%A7%92%E8%89%B2.md)
- 圖片：透明背景、所有圖同樣大小、角色腳底貼齊圖片下緣
- 換裝：開一個新資料夾，在 `character.json` 寫 `"skinOf": "原角色資料夾名"` 和 `"skinName": "衣服名稱"`，就會出現在「換衣服」選單
- 角色之間的對話寫在 `characters/dialogs.json`
- 用 AI 畫新立繪可以參考 CrossPet 的 [角色生圖提示詞](https://github.com/lokicorvus/crosspet/tree/main/docs/prompts)
